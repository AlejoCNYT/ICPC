## English

This repository is dedicated to the preparation, practice, and review of competitive programming problems from world-renowned platforms like **UVA Online Judge**, **Codeforces**, and others, following **ICPC** official competition standards.

### 🚀 Repository Structure

| Problem / File | Platform | Main Approach / Technique | Language |
| :--- | :---: | :--- | :---: |
| `uva100_the_3n_plus_1_problem.py` | **UVA 100** | Collatz sequence optimized via **Memoization** and dynamic path back-propagation. | Python |
| `230B-TPrimes` | **Codeforces 230B** | Number theory, **Sieve of Eratosthenes**, and efficient verification of prime perfect squares. | Python |
| `223_Rectangle Area` | **LeetCode / UVA 223** | Algorithmic geometry and 2D area intersection computing. | Python |

### 🧠 Concepts Reviewed
* **Optimization & Dynamic Programming:** Utilizing cache (`memo`) structures to prevent redundant calculations of overlapping subproblems.
* **Number Theory:** Exploiting prime properties and optimizing time complexity within factorization loops.
* **Computational Geometry:** Analytical handling of Cartesian coordinates and region overlapping.
